# Operations & Utility Scripts

This directory contains standalone operational, diagnostic, and maintenance scripts.

- `check_data.py`: Quick diagnostic script to inspect orders and idempotency records in the database.
- `check_tables.py`: Quick diagnostic script to verify database tables and schema in PostgreSQL or SQLite.

## Running Scripts

Execute from the repository root:

```bash
python scripts/check_data.py
python scripts/check_tables.py
```
